# Phase 11 — UI Design Contract

> Visual and interaction contract for the active-workout re-skin (HIGH RISK — F13). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Stack note:** This is an Expo / React Native + NativeWind 4 app, NOT a web/shadcn project. There is no `components.json` and no shadcn registry — the shadcn initialization gate and registry-safety gate are **not applicable**. The design system is the in-repo **Forge** system landed in Phase 8 (`THEMES.forge` → `app/tailwind.config.js`, components in `app/components/ui/*`). This phase consumes those tokens; it declares no new tokens.
>
> **Re-skin scope:** Presentational re-skin over a **frozen offline-first write path** (D-17). The mutation/queue layer (`useAddSet/useUpdateSet/useRemoveSet/useFinishSession`, scope-binding, persister) is untouched. `npm run test:f13-brutal` must stay green and the ≤3s log-set budget must hold.

**NativeWind box-styling rule (carried from Phase 10 memory):** Pressable/Touchable box styling (bg / border / radius / size) MUST live in `className`, never in an inline `style()` callback (renders naked under NativeWind 4). Keep `style()` only for shadow/opacity/animated values. Root cause of the Phase 10 "naked re-skin" bug — applies to every ✕-delete, input field, and button in this phase.

## Spacing Scale

Declared values (multiples of 4; transcribed from `forge-screens.jsx` FWorkout / FFinishOverlay / FDraftResumeOverlay):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, progress-dot gaps (6px exception below), set-number badge inset |
| sm | 8px | Input-field grid gap, header pill gap, stat-row gap, dot gap (6px exception) |
| md | 16px | Card horizontal padding, screen gutter (`0 16px`), card-to-card vertical rhythm |
| lg | 20px | Title block padding (`12px 20px`), card inner radius rhythm |
| xl | 24px | Overlay card padding (`padding: 24`) |
| 2xl | 32px | Screen bottom padding (`0 0 32px`) |

**Exceptions (declared, intentional — each justified, all transcribed verbatim from the Phase-8-approved Forge mock, not ad-hoc):**
- **6px** — progress-dot height and inter-dot gap (FWorkout lines 373–387). Sub-grid micro-spacing for the dot strip; not a layout token. Justified: dot-strip micro-rhythm has no 4-multiple equivalent that reads correctly at this scale.
- **14px** — logged-set row vertical padding (`14px 16px`) and finish-overlay timer/meta strips. Forge row rhythm from the mock. Justified: row density was tuned in the approved Forge mock to fit the set-table grid; bumping to 16px overflows the ≤3s-scan hot-path table.
- **44px** — minimum touch target for the trailing ✕-delete icon and the circular back button (rendered 40px visually per mock, hit-slop expanded to 44px for a11y). Justified: iOS HIG minimum tap target — an accessibility requirement, not a spacing choice.
- **50px** — full-width "Klart / Done" CTA button height (FWorkout input row, lines 468–495). Justified: this is a **component height**, not a layout spacing token; transcribed from the approved Forge mock. (Also referenced in the component-heights note below; listed here explicitly so the spacing contract is unambiguous.)
- **52px / 56px** — additional control heights (overlay primary buttons 52px; input fields 56px per D-10 "tall"; draft-resume "Resume" 56px). Component heights, not spacing tokens; transcribed from the approved Forge mock.

## Typography

> **Carry-forward declaration (project-level override — NOT a new type-scale declaration):**
> This phase is a **re-skin**. The type scale below is **inherited from the already-approved Phase 8 Forge design system** (`THEMES.forge` + `forge-screens.jsx`, signed off in Phase 8 DSGN-02). Phase 11 **applies** the existing scale to the active-workout surfaces — it **declares no new font sizes and introduces no new type roles**. The full in-use scale is captured here verbatim so the executor has a single source of truth, not because Phase 11 is defining a fresh scale.
>
> **Why more than 4 sizes:** the Forge system is an approved, established multi-size design system (display titles, overlay headings, stat numerals, input values, body, CTA labels, meta labels, and uppercase micro-labels are all distinct, pre-existing roles in the Phase 8 mock). The default 4-size cap targets *new ad-hoc declarations*; it does not apply to a re-skin that consumes a previously approved system. This is an explicit, justified override: the table below is a **transcription of the approved Forge scale in use on these screens**, not an 8-size invention. No checker action is needed beyond recognizing the inherited-system status.

Forge type scale for the surfaces in this phase. Weights: **600 (semibold)** and **700 (bold)** via the dedicated Inter Display families (`font-display-semibold`, `font-display-bold`); body/labels use System at 500/600. RN does not synthesize weights — each weight is its own family (DSGN-02, OQ-4).

| Role | Size | Weight | Line Height | Family / Usage |
|------|------|--------|-------------|----------------|
| Display (screen title / exercise name) | 32px | 700 | 1.1 | `font-display-bold`, letter-spacing -1.1. Workout title (FWorkout line 369). |
| Overlay heading | 26px | 700 | 1.15 | `font-display-bold`, letter-spacing -0.8. "Avsluta passet?" / "Återuppta passet?" (FFinishOverlay 1622, FDraftResume). |
| Stat numeral (logged-set weight/reps, finish-stats value) | 18px | 600–700 | 1.0–1.2 | `font-display-semibold` + tabular-nums, letter-spacing -0.3/-0.4. Set table values + FFOStat (line 1684). |
| Input value | ~22px display | 600 | 1.0 | `font-display-semibold` + tabular-nums. Large value in ForgeInput with unit label underneath (D-10). |
| Body / overlay copy | 15px | 400–500 | 1.4 | System. Overlay body sentence (FFinishOverlay 1626), draft-resume body. |
| CTA / button label | 14–16px | 600 | 1.0 | System, letter-spacing -0.2. "Klart" 16px, header "Avsluta" 14px, overlay buttons 15px. |
| Label / meta | 13px | 500–600 | 1.3 | System + tabular-nums where numeric. Timer pill (13px), "Förra: 105 × 6" prev-value, meta strip. |
| Micro-label (uppercase) | 10–11px | 600–700 | 1.0 | System, letter-spacing +0.8 to +1.5, uppercase. Column headers (`# WEIGHT REPS RPE`, 10px), "SET 4" input label (11px accent), FFOStat unit label (9–10px). |

All eight roles above are **pre-existing Phase 8 Forge roles** — none are introduced by this phase. Body line-height 1.4–1.5; heading line-height 1.1–1.2. Numerals (weights, reps, RPE, timer, stat values, counts) MUST render tabular-nums so figures align (DSGN-03).

## Color

Forge tokens only (light DEFAULT pair + `dark:` sibling). 60/30/10 maps to the Forge surface hierarchy.

| Role | Token (light → dark) | Usage |
|------|----------------------|-------|
| Dominant (60%) | `forge-bg` `#FAFAF7 → #000000` | Screen background, scroll surface, input-field fill in overlays |
| Secondary (30%) | `forge-surface` / `surface2` / `surface3` `#FFFFFF / #F2F1EC / #E8E7E1 → #0E0E10 / #18181B / #222226` | Logged-set card, overlay card (`surface2` dark / `surface` light), back-button circle, progress-dot remaining track, finish-stat cells |
| Accent (10%) | `forge-accent` `#E14E10 → #FF5A1F` (soft: `forge-accentSoft`) | See reserved-for list |
| Success | `forge-success` `#1E9E45 → #30D158` | Logged-set `checkCircle` icon, saved-toast pill background ("Passet sparat") |
| Destructive | `forge-danger` `#D70015 → #FF453A` | ONLY the draft-resume "Avsluta sessionen / End session" button (data-loss-adjacent, D-16). Used as text/border on a ghost button, not a filled red CTA. |
| Muted text | `forge-text2` / `text3` | RPE `–` placeholder (D-05), prev-value chip, column headers, meta strips |

**Accent reserved for (explicit — never "all interactive elements"):**
1. Header live-timer pill (`accentSoft` bg + `accent` text + `accent`-tinted border, D-07).
2. Header "Avsluta / Finish" button (filled accent — terminal state is intended, NOT red, D-16 + PITFALLS §6.6).
3. Per-card progress dots: **done** dots filled `accent`; **current** dot `accentSoft` fill + `accent` border; **remaining** dots `surface2` (D-02).
4. Set-number badge (filled `accent` circle, `accentText` numeral).
5. Input row: accent-tinted field background (`rgba(accent,0.04–0.05)`), accent field borders, "SET N" uppercase label, and the full-width "Klart / Done" CTA (filled accent + check icon, D-10).
6. Finish-overlay primary "Avsluta / Finish" button (filled accent, D-16) — secondary "Fortsätt / Continue" uses `surface3` (neutral, not accent).
7. Draft-resume "Återuppta / Resume" primary button (filled accent) + the "Live" pill.

**Explicitly NOT accent:** logged-set success check (uses `forge-success`), saved-toast (uses `forge-success`), "Fortsätt/Continue" secondary (neutral `surface3`), ✕-delete affordance (muted `text2`/`text3`, turns `danger` only on press-feedback — recoverable, no confirm per Claude's Discretion).

**OMITTED (D-06, Phase 13 owns it):** the PR celebration banner gradient (`gradFrom → gradTo`) and per-set `trophy` markers. All sets render the plain `checkCircle` success icon. No inert/scaffolded PR slots.

## Copywriting Contract

All strings routed through `t()` with sv + en keys (D-14, flat-key convention per Phase 8 D-10). User-created content (exercise names, notes) is stored as written, never translated (I18N-05). Numbers format per active locale; Swedish decimal handling preserved.

> **CTA brevity note (intentional — these are not generic system labels):** The single-word CTAs in this phase — **"Klart" / "Done"**, **"Avsluta" / "Finish"**, **"Fortsätt" / "Continue"**, **"Återuppta" / "Resume"** — are deliberately verb-only for the **hot-path tap loop** (≤3s log budget, F13). Each is **paired with an icon and/or unambiguous overlay context** that supplies the noun: "Klart" + check icon on the full-width log-set CTA; "Avsluta" + check inside a "Finish workout?" overlay; "Återuppta" + play icon under a "Resume workout?" heading. The accompanying overlay heading or button icon is the object — a verb+noun label here would add scan-cost to the most-repeated action in the app without adding clarity. These are scoped CTAs, not reusable system-wide labels.

| Element | Copy (sv → en) |
|---------|----------------|
| Primary CTA — log set | **"Klart" → "Done"** (full-width accent button + check icon; the hot-path action, D-10) |
| Header finish button | **"Avsluta" → "Finish"** (accent pill, D-09) |
| Header timer | live `MM:SS` elapsed (e.g. `42:18`), tabular-nums, derived from `started_at` via reused `formatElapsed` (D-07) |
| Column headers | `# · Vikt · Reps · RPE` → `# · Weight · Reps · RPE` (10px uppercase, D-03) |
| Input-row label | **"Set N"** (accent uppercase) + prev-value **"Förra: {w} × {r}" → "Previous: {w} × {r}"** (F7, D-10) |
| RPE absent | muted **"–"** (en dash) when the set has no RPE value (always-rendered column, D-05) |
| Delete affordance | trailing **✕** icon, `accessibilityLabel` **"Ta bort set" → "Remove set"** (replaces swipe, D-04; no confirm — recoverable, mirrors v1) |
| Finish overlay heading | **"Avsluta passet?" → "Finish workout?"** |
| Finish overlay body | **"{N} set sparade på {MM:SS}. Lägg gärna en notering om hur passet kändes." → "{N} sets logged in {MM:SS}. Add a note about how the session felt."** |
| Finish overlay stats row | three cells: **{N} / "Set"** , **{Σ kg} / "kg"** , **{MM:SS} / "min"** — client-derived (D-08). Numerals tabular. |
| Finish overlay buttons | secondary **"Fortsätt" → "Continue"** (neutral), primary **"Avsluta" → "Finish"** (accent + check, D-16) |
| Draft-resume heading | **"Återuppta passet?" → "Resume workout?"** |
| Draft-resume body | **"Du har ett pågående pass från {tid} med {N} set sparade på {plan}." → "You have a workout in progress from {time} with {N} sets logged on {plan}."** |
| Draft-resume buttons | primary **"Återuppta" → "Resume"** (accent + play icon), secondary **"Avsluta sessionen" → "End session"** (DANGER ghost — data-loss-adjacent, D-16) |
| Saved toast | **"Passet sparat" → "Workout saved"** (success pill, bottom-centered above tab bar, check icon) |
| Empty state heading (defensive) | **"Inget att logga" → "Nothing to log"** (re-skin existing "Inget set är loggat" defensive copy, D-13) |
| Empty state body | **"Den här planen har inga övningar kvar. Gå tillbaka och lägg till övningar." → "This plan has no exercises left. Go back and add exercises."** + accent back button. Reachable only if a plan's exercises were removed mid-pass. |
| Loading states | **"Laddar…" → "Loading…"** (session hydration) ; **"Återställer pass…" → "Restoring workout…"** (cold-start draft restore) — both re-skinned to Forge, i18n'd (D-14) |
| Error state | Logging never blocks on network (offline-first optimistic write). On a genuine finish-session error, surface the existing inline error path (preserved via D-17 `mutate` `onError`); copy: **"Kunde inte avsluta passet. Försök igen." → "Couldn't finish the workout. Try again."** No data is lost — the set/session stays queued. |

**Destructive actions in this phase:**
1. **Delete logged set (✕):** recoverable (re-add), **no confirmation dialog** — mirrors v1, fits the grid, preserves ≤3s flow. Affordance muted, not red.
2. **End orphaned draft session ("Avsluta sessionen"):** data-loss-adjacent → **danger-colored ghost button** inside the draft-resume overlay (the one place red is correct, D-16). The overlay itself is the confirmation surface (force-decision, no backdrop-tap dismiss).

## Motion & Interaction Contract

Reanimated 4 (already in stack — no new dep). Default spring curve: **damping 18, stiffness 220** (spec §07). Motion is additive polish, NEVER a gate on the write (F13).

| Surface | Animation | Duration | Gating |
|---------|-----------|----------|--------|
| Set logged ("Klart", MOTN-01) | Logged row slides in from bottom + check icon scales 0.8→1 + haptic `Haptics.impactAsync(Medium)` | ~220ms | Visual NOT gated. **Haptic gated behind `fm:haptics`** pref (default on) via `getPref` Zod-catch read (D-12, MOTN-05). Fire-and-forget; never blocks the optimistic `mutate`. |
| Overlay open — Avsluta / draft-resume / saved-toast (MOTN-04) | Backdrop opacity 0→0.5 + card translateY 24→0, spring | ~240ms | None. All **inline-rendered, no Modal portals** (D-15, SKIN-05). |
| PR celebration | **EXCLUDED** — Phase 13 (D-06, D-11). | — | — |

**Interaction invariants (MUST preserve — D-10, D-17):**
- Keyboard wiring on input fields: `decimal-pad`/`number-pad`, `inputMode`, `selectTextOnFocus`, `returnKeyType:"done"`, RHF `mode:"onSubmit"`, prefill (session-prefill → F7 fallback).
- `mutate` (not `mutateAsync`) for all set/finish writes; synchronous navigation after `finishSession.mutate`.
- `AvslutaOverlay` manual keyboard-height lift (`paddingBottom = keyboardHeight + 16`) preserved through the re-skin.
- Hydration gate, `useFocusEffect` modal-state cleanup, second `OfflineBanner` instance — all preserved.
- Backdrop-tap dismiss on Avsluta (recoverable); force-decision (no dismiss) on draft-resume (orphan must be resolved).

## Layout Contract (per-surface, from CONTEXT decisions + forge-screens.jsx)

- **Screen model (D-01):** single vertical `ScrollView` of stacked Forge exercise cards (NOT the mock's single-exercise pagination). Drop "Övning 1/6" framing and the "Up next" card.
- **Custom header (D-09):** `headerShown:false`; in-content Forge header = circular back (40px, `surface` + `border`) · centered timer pill (D-07) · accent "Avsluta" button. Owns its safe-area inset + back-nav.
- **Per-card progress dots (D-02):** flex-strip of `6px` bars (done=accent / current=accentSoft+accent border / remaining=surface2) + trailing "N / M" counter, replacing the v1 "3/4 set klart" chip.
- **Logged-set table (D-03):** grid `32px 1fr 1fr 56px 36px` → `# · weight · reps · RPE · action`; set-number badge (accent circle), display-font numerals with `kg` unit suffix, RPE always-shown (`–` when null, D-05), trailing ✕-delete (D-04). Tap row = inline edit (`EditableSetRow` preserved).
- **Input row (D-10):** accent-tinted card footer; grid `1fr 1fr 60px` (weight / reps / rpe-small) of 56px ForgeInput fields (large display value + small uppercase unit label underneath) + full-width 50px accent "Klart" button with check icon. (The 50px CTA height is listed under Spacing → Exceptions as a component height.)
- **Finish overlay (D-08):** trophy-block hero (gradient — note: this is the overlay's own icon block, NOT the omitted PR banner) + heading + body + notes textarea w/ counter + 3-cell client-derived stats row + neutral "Fortsätt" / accent "Avsluta" buttons.
- **Overlays live inline (D-15):** Avsluta inside `workout/[sessionId].tsx`; draft-resume + saved-toast inside `(tabs)/index.tsx` (re-skin chrome only — overlay/toast LOGIC is offline-critical, restyle only).
