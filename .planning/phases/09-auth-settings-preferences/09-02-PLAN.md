## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AsyncStorage → Settings controls | fm:* pref reads on mount may be tampered |
| Settings → Supabase profiles | weekly_goal write crosses into RLS storage |
| language control → i18next | onChange feeds a resolved code into changeLanguage |
| cold launch → LocaleBootstrap | stored fm:language pref drives the splash-gated language apply |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-06 | Tampering | Settings fm:* reads on mount | mitigate | All reads via lib/prefs.ts catch-parse idiom (default fallback, never throws) |
| T-09-07 | Elevation/Info-disclosure | weekly_goal update (BOLA) | mitigate | `.eq("id", session.user.id)` + own-row RLS policy; verify returned row; CHECK 1..7 server-side |
| T-09-08 | Tampering | language onChange → changeLanguage | mitigate | resolveLanguage returns only `'sv'|'en'` literal union; no free text reaches the engine |
| T-09-09 | DoS | LocaleBootstrap splash gate | mitigate | Preserve `.finally(setLocaleReady(true))` fail-open — corrupt locale pref can never hang splash |
| T-09-10 | Spoofing/Info-disclosure | Sign-out cross-user cache | mitigate | Reuse existing signOut chain verbatim (queryClient.clear → supabase.auth.signOut) — do not regress FIT-5 |
| T-09-11 | Privacy/over-permission | notifications toggle | accept | Stored pref only — NO expo-notifications, NO OS prompt this phase (D-07); permission deferred to Phase 14 |
</threat_model>
