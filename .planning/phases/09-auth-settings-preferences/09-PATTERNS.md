### `lib/prefs.ts` (NEW — typed `fm:*` read/write) (utility, request-response)

**Analog:** `app/(app)/(tabs)/settings.tsx` (lines 43-62) + `app/_layout.tsx` `LocaleBootstrap` (lines 154-169). The **corrupt-tolerant `.catch(default).parse()` idiom is the established repo standard** and a documented security mitigation (T-08-03/T-08-04). Replicate it for `fm:units`, `fm:haptics`, `fm:notifications`, `fm:language`.

**Read idiom** (`settings.tsx` lines 44-51):
```typescript
void AsyncStorage.getItem("fm:theme").then((v) => {
  const parsed = z.enum(["system", "light", "dark"]).catch("system").parse(v);
  setStored(parsed);
  setColorScheme(parsed);
});
```

**Write idiom** (`settings.tsx` lines 57-61):
```typescript
void AsyncStorage.setItem("fm:theme", value).catch(() => {
  console.warn("[settings] AsyncStorage write failed — theme not persisted");
});
```

**Apply to the 4 new keys (same idiom, new schemas):**
```typescript
const units = z.enum(["metric", "imperial"]).catch("metric").parse(v);          // fm:units
const language = z.enum(["system", "sv", "en"]).catch("system").parse(v);        // fm:language
// Boolean switches: AsyncStorage stores strings — store "true"/"false" and parse with an
// enum-catch (NOT JSON.parse, which throws on garbage before .catch can fire — RESEARCH Pattern 1 note):
const haptics = z.enum(["true", "false"]).catch("true").transform((s) => s === "true").parse(v);   // default ON (D-08)
const notifications = z.enum(["true", "false"]).catch("false").transform((s) => s === "true").parse(v);
```
> Keep all four reads/writes inside `prefs.ts` for DRY (RESEARCH §Alternatives: a persisted-Zustand store is **rejected** — zero precedent; `font-store`/`persistence-store` are non-persisted per-launch flags). Per-key reads match `fm:theme`/`fm:language` exactly.

### `lib/units.ts` (NEW — kg↔display helper) (utility, transform)

**Analog:** `lib/i18n.ts` — a pure module with no React/JSX, importable from both screens and Node `tsx` test scripts. No in-repo unit helper exists, so the *structure* (pure exported functions, no side effects) is the borrowed pattern; the math is net-new (RESEARCH Pattern 4 / D-01).

**Pattern to author** (RESEARCH Pattern 4, [CITED: CONTEXT D-01]):
```typescript
const KG_PER_LB = 0.45359237;                            // exact
const roundHalf = (n: number) => Math.round(n * 2) / 2;  // nearest 0.5 (D-01 plate granularity)
export type UnitPref = "metric" | "imperial";
export function toDisplayWeight(kg: number, unit: UnitPref): number {
  if (!Number.isFinite(kg)) return 0;                    // non-finite guard (Pitfall 5)
  return unit === "imperial" ? roundHalf(kg / KG_PER_LB) : kg;
}
export function formatWeight(kg: number, unit: UnitPref): string {
  const v = toDisplayWeight(kg, unit);
  return `${v} ${unit === "imperial" ? "lb" : "kg"}`;    // 100→"100 kg", 220.5 stays
}
```
> **Keep it pure + dependency-injectable** so `scripts/test-units.ts` can import it in a Node `tsx` run with no Expo runtime. The screen applies the `numStyle` tabular-nums font (DSGN-03); the helper returns data only. **No retrofit to existing weight-display screens this phase (D-02).**

**NEW `resolveLanguage` to add** (three-state → two-state; RESEARCH Pattern 2, D-10/D-11). Inject `languageCode` for testability:
```typescript
export type LanguagePref = "system" | "sv" | "en";
export function resolveLanguage(pref: LanguagePref, deviceLang?: string): "sv" | "en" {
  if (pref === "sv" || pref === "en") return pref;
  const lang = deviceLang ?? Localization.getLocales()[0]?.languageCode;
  return lang === "sv" ? "sv" : "en";   // D-11: Swedish device → sv, anything else → en
}
```

### `app/_layout.tsx` `LocaleBootstrap` (MODIFY) (provider/bootstrap, event-driven)

**Analog:** the same function, lines 154-169 — extend two-state → three-state. **This is a REQUIRED edit** (RESEARCH Pitfall 2): the current `z.enum(["sv","en"]).catch("sv")` silently rewrites a stored `'system'` back to `'sv'` on cold launch.

**Current (two-state)** (lines 156-167):
```typescript
void AsyncStorage.getItem("fm:language")
  .then((v) => {
    const l = z.enum(["sv", "en"]).catch("sv").parse(v);
    return i18n.changeLanguage(l);
  })
  .catch(() => { /* keep init language */ })
  .finally(() => setLocaleReady(true));   // FAIL-OPEN — must preserve (DoS/T-08-04)
```

**Target (three-state — extend enum + route through resolver):**
```typescript
const pref = z.enum(["system", "sv", "en"]).catch("system").parse(v);
return i18n.changeLanguage(resolveLanguage(pref));   // resolver implements D-11
```
> **Preserve the `.finally(setLocaleReady(true))` fail-open** — it is the splash-gate DoS mitigation; a corrupt locale pref must never hang the splash.
