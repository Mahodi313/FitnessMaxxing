## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → Supabase | Seed insert crosses into RLS-gated exercises table with the signed-in user_id |
| device AsyncStorage → app | The fm:exercises_seeded flag is device-local untrusted state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-06 | Spoofing | Seed insert with a spoofed/null user_id | mitigate | Seed runs through useCreateExercise with `user_id = session.user.id`; RLS `with check (user_id = (select auth.uid()))` rejects any other user_id; bootstrap is gated on `userId` presence inside the auth tree |
| T-10-07 | Tampering | Tampered fm:exercises_seeded flag causes re-seed | accept | Re-seed is idempotent (deterministic UUIDs + upsert ignoreDuplicates) — a flipped flag at worst re-enqueues no-op upserts; non-sensitive marker, single-user V1 |
| T-10-08 | Denial | Seed batch blocks first render | mitigate | Bootstrap is no-op render + fire-and-forget `.then().catch()` (fail-open); never awaited, never blocks the splash or Stack |
| T-10-09 | Tampering | Malformed muscle_group from legacy/tampered data | mitigate | resolveMuscleGroupKey is total (`?? 'other'`); test-muscle-group covers unknown + null + empty |
| T-10-SC | Tampering | npm/pip/cargo installs | accept | No new package dependencies; uuidv5 (if used) ships with an already-present dep or hardcoded UUIDs avoid any install |
</threat_model>
