# Phase 8 — UI Design Contract (Forge Foundation)

> Visual and interaction contract for the v2.0 Forge design-system foundation. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Source of truth:** `app/design v2/Sources/design/lib.jsx` (`THEMES.forge`, `I18N`, `numStyle`, primitives) and `app/design v2/Sources/design/forge-screens.jsx` (component variant/size APIs). All values below are transcribed from those files — none are invented. Token→tailwind mechanics are locked by `.planning/research/ARCHITECTURE.md` §1/§2/§7.
>
> **Phase boundary:** This phase builds the foundation + a dev-only gallery. NO production screen is re-skinned. ProgressRing/Sparkline are STATIC (animations are Phase 12). Logo/AppIcon ship as components only (no `app.json` asset swap).

## Spacing Scale

Forge uses a 2px-granular scale derived from `forge-screens.jsx` (4-multiples for layout gaps; sub-4 values only for hairline/optical insets). Declared layout tokens (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, chip inner gap, progress-dot gap |
| sm | 8px | Compact element gaps, stat-grid gutters, input-grid gaps |
| md | 16px | Default screen horizontal padding (cards live at `0 16px`), card-to-card gap baseline |
| lg | 20px | Card inner padding (`16–20px`), title-block horizontal padding |
| xl | 24px | Section padding, hero-card padding, overlay-card padding |
| 2xl | 32px | Screen bottom padding (non-tab), CTA top offset |
| 3xl | 100px | Bottom padding on tab screens (clears the floating TabBar) |

**Border-radius scale (from `THEMES.forge.radius` — LOCKED, map to `borderRadius` in tailwind.config as `forge-sm/md/lg/xl`):**

| Token | Value | Usage |
|-------|-------|-------|
| forge-sm | 10px | Small inner blocks, icon tiles, segmented-control pills |
| forge-md | 14px | Fields, inputs, list rows, chips-on-rows, secondary buttons |
| forge-lg | 20px | Cards, hero card, stat grids, chart card |
| forge-xl | 28px | Largest containers / overlay cards (overlay cards use 22 — see exceptions) |

**Exceptions (optical, from reference screens — do NOT normalize to the 4-grid):**
- Chip vertical padding `4px 9px`; chip radius `8px`.
- Pill / toast radius `999px` (full-round saved-toast, range selectors).
- Overlay (modal) card radius `22px`, padding `24px`.
- Icon tiles `28/32/36/44/52px`, toggle `44×26`, avatar `56px` — fixed component dimensions, not spacing.
- Tab bar: `paddingTop 10`, `paddingBottom 28` (home-indicator safe area).
- Touch targets: primary CTAs `56–64px` tall; secondary/finish buttons `36–52px`; list rows `min-height 52px`.

## Typography

Body stays **System (SF Pro)**. **Display = Inter Display**, **Mono = JetBrains Mono**. Numerals in stats/inputs/axes use tabular-nums (`numStyle`: `fontVariantNumeric: 'tabular-nums'`, `fontFeatureSettings: '"tnum","ss01"'`) per DSGN-03.

Three weights only (per D-04): Regular (400) / SemiBold (600) / Bold (700). Inter Display Bold drives display numerals + headings; SemiBold drives body emphasis + labels; mono Regular drives numeric cells/axes.

| Role | Family | Size | Weight | Line Height | Notes |
|------|--------|------|--------|-------------|-------|
| Display hero (e1RM, big numerals) | Inter Display | 52px | 700 | 1.0 | `letterSpacing: -2`, tnum |
| H1 page title | Inter Display | 36px | 700 | ~1.0 | `letterSpacing: -1.2` |
| H1 auth hero | Inter Display | 44px | 700 | 1.02 | `letterSpacing: -1.4` |
| H1 screen title (workout/chart/detail) | Inter Display | 32px | 700 | 1.0–1.1 | `letterSpacing: -1.1` |
| H2 overlay title | Inter Display | 26px | 700 | ~1.1 | `letterSpacing: -0.8` |
| Stat value (cards/grids) | Inter Display | 28–30px | 700 | ~1.0 | `letterSpacing: -0.6 to -1`, tnum |
| Stat value (compact) | Inter Display | 18–22px | 700 | 1.0 | tnum |
| Input numeral (ForgeInput/Stepper) | Inter Display | 20–22px | 700 | 1.0 | tnum, unit label below |
| Body | System | 15–16px | 400–500 | 1.4 | screen copy, field values |
| Label (row label) | System | 15px | 500 | — | `letterSpacing: -0.2` |
| Caption / meta | System | 12–13px | 500–600 | 1.4–1.5 | secondary text (`text2`/`text3`) |
| Eyebrow / section header | System | 10–13px | 600–700 | — | UPPERCASE, `letterSpacing: 1–1.5` |
| Mono numeric cell / chart axis | JetBrains Mono | 10–18px | 400–600 | — | set numbers, axis ticks, tnum |
| Tab label | System | 10.5px | 500/600 | — | active=600, `letterSpacing: -0.1` |

**Note for checker:** This is a design-system foundation — more than 4 sizes is intentional and prescribed by the handoff (`forge-screens.jsx` uses a full type ramp across 17 screens). The constraint that matters here is the **3-weight cap** (400/600/700) and the **2-family display/mono split**, both honored.

## Color

60/30/10 maps cleanly to Forge: `bg` dominates (60%), `surface`/`surface2`/`surface3` carry cards & chrome (30%), `accent` orange is reserved for ~10%. Values are LOCKED from `THEMES.forge` (mirror into `tailwind.config.js` `forge.*` per ARCHITECTURE.md §1; rgba tokens via opacity-modifier syntax e.g. `text-forge-text/62`).

| Role | Dark | Light | Usage |
|------|------|-------|-------|
| Dominant bg (60%) | `#000000` | `#FAFAF7` | App background (`bg-forge-bg`) |
| Surface (30%) | `#0E0E10` | `#FFFFFF` | Cards, fields, list rows (`bg-forge-surface`) |
| Surface2 | `#18181B` | `#F2F1EC` | Icon tiles, segmented tracks, inactive chips |
| Surface3 | `#222226` | `#E8E7E1` | Active segment, secondary button bg |
| Text (primary) | `#FFFFFF` | `#0A0A0A` | Headings, primary copy |
| Text2 | `rgba(255,255,255,0.62)` | `#4D4D4D` | Secondary copy → `text-forge-text/62` (dark) |
| Text3 | `rgba(255,255,255,0.38)` | `#8B8B8B` | Tertiary/meta, eyebrows → `text-forge-text/38` (dark) |
| **Accent (10%)** | `#FF5A1F` | `#E14E10` | See reserved-for list below |
| AccentText | `#FFFFFF` | `#FFFFFF` | Text/icons on accent fills |
| AccentSoft | `rgba(255,90,31,0.14)` | `rgba(225,78,16,0.10)` | Accent-tinted backgrounds (banners, soft chips, icon tiles) |
| Border | `rgba(255,255,255,0.08)` | `rgba(0,0,0,0.07)` | Hairline borders → `border-forge-text/8` style |
| BorderStrong | `rgba(255,255,255,0.14)` | `rgba(0,0,0,0.14)` | Emphasized borders (stepper, overlay card) |
| Success | `#30D158` | `#1E9E45` | Positive deltas, checkmarks, saved-toast |
| Warn | `#FFD60A` | `#B68000` | Reserved (not used in Phase 8 gallery) |
| Destructive | `#FF453A` | `#D70015` | Sign-out, remove/delete affordances only |
| GradFrom→GradTo | `#FF7A2E`→`#FF2D55` | `#FF7A2E`→`#FF3D5E` | Brand gradient: Logo/AppIcon, ring fill, PR/trophy badges |

**Accent reserved for (explicit — NOT "all interactive elements"):**
1. Primary CTA fills (ForgeButton `primary`: sign-in, start workout, create plan, done/log-set).
2. The single active/selected affordance per control (active tab icon+label, selected filter pill, active segment text, current set indicator).
3. Inline links / micro-actions (`+ Add exercise`, `New plan`, `Cancel`/`Save` text buttons, `Forgot password?` link in accent).
4. "Last value" emphasis numerals (the prior set, e.g. `105 × 6` in accent) — the Core-Value highlight.
5. Accent-soft tints: active-session banner, PR celebration banner, settings icon tiles, workout input-row background.
6. Live/progress indicators (pulsing session dot, progress-bar fill, ProgressRing stroke via gradient).

**Brand gradient (`gradFrom→gradTo`)** is reserved for the Ascend brand surfaces ONLY: Logo, AppIcon, brand-mark tiles in headers, the PR trophy badge, and the ProgressRing fill. The barbell icon is a **content** icon (plan cards, Planer tab, exercise rows) — never rendered in brand gradient (per README "barbell is content, Ascend is brand-only").

## Component Inventory (DSGN-04/05/06)

All primitives live in `app/components/ui/`. APIs derived from actual usage in `forge-screens.jsx` (D-02: explicit variant/size props, not className passthrough). Every component supports light + dark via `dark:` variant.

### ForgeButton (DSGN-04)
- **Props:** `variant: 'primary' | 'secondary' | 'ghost' | 'destructive'`, `size: 'lg' | 'md' | 'sm'`, `icon?` (leading or trailing per usage), `iconPosition?: 'leading' | 'trailing'`, `loading?`, `disabled?`, `fullWidth?`, `onPress`.
- **variant→style:**
  - `primary`: `bg-forge-accent` fill, `accentText`, accent shadow (dark: `0 8–12px 24–32px accent/40–50`); heights 56–64.
  - `secondary`: `bg-forge-surface3` (or surface), `text-forge-text`, no shadow (e.g. overlay "Continue").
  - `ghost`: transparent + `border-forge-border`, `text-forge-text`; used for "Continue"/bordered actions.
  - `destructive`: transparent + `border-forge-border`, `text-forge-danger` (sign-out, "Remove from plan").
- **size→height:** `lg` 56–64 (radius `forge-lg` 16–18), `md` 50–52 (radius `forge-md` 14), `sm` 36 (radius 18 pill, e.g. workout "Finish").
- Label weight 600, `letterSpacing: -0.2`, `font` (System) family.

### ForgeField (DSGN-04)
- **Props:** `icon?` (Icon name), `placeholder`, `value`, `onChangeText`, `secureTextEntry?`, `keyboardType?`, `state?: 'default' | 'focused' | 'error'`, `multiline?`.
- **Style:** height 56 (single-line) / `minHeight 92–110` (multiline), radius `forge-md` 14, `bg-forge-surface`, `border-forge-border`; **focused** = `border-2 border-forge-accent`; leading icon `text-forge-text/38`; value 16px `text-forge-text`, placeholder `text-forge-text/38`.
- Search-field variant: height 48, leading magnifier icon.

### ForgeCard (DSGN-04)
- **Props:** `padding?: 'sm' | 'md' | 'lg'` (default `lg`=18–20), `radius?: 'md' | 'lg' | 'xl'` (default `lg`=20), `interactive?` (adds chevron affordance + press feedback), `tint?: 'surface' | 'accentSoft'` (default surface), children.
- **Style:** `bg-forge-surface`, `border-forge-border`, radius `forge-lg`. The base container for hero card, plan rows, stat grids, session rows, settings cards.

### ForgeStat (DSGN-04, tnum)
- **Props:** `label` (UPPERCASE eyebrow), `value` (Inter Display, tnum), `unit?`, `delta?: { value, direction: 'up' | 'down' }` (success/danger pill), `size?: 'sm' | 'md' | 'lg'`, `align?: 'left' | 'center' | 'right'`.
- **size→value font:** `sm` 18 / `md` 22 / `lg` 28–30. Label 10–11px UPPERCASE `text-forge-text/38`, weight 600, `letterSpacing 0.8–1`.

### ForgeChip (D-01)
- **Props:** `icon?` (rendered in accent), `variant?: 'default' | 'accent' | 'success'`, children.
- **Style:** `inline-flex`, padding `4px 9px`, radius 8, `bg-forge-surface2`, `border-forge-border`, 12px weight-600 `text-forge-text/62`; accent icon `12px strokeWidth 2`.

### SettingsRow (D-01)
- **Props:** `icon` (in accent-soft tile), `label`, `value?` (right-aligned), `chevron?`, `toggle?` (+ `toggleValue`, `onToggle`), `control?` (inline segmented control slot), `onPress?`, `last?` (suppress bottom border).
- **Style:** `min-height 52`, padding `14px 16px`, bottom `border-forge-border`; icon tile 28×28 radius 8 `bg-forge-accentSoft` + 15px accent icon; label 15px weight 500. Toggle 44×26 pill (`bg-forge-accent` when on, 22px white knob). Wrapped by `SettingsSection` (UPPERCASE label + rounded `bg-forge-surface` group container).

### TabBar shell (D-01, re-skin only — no navigation behavior change)
- **Items:** `plans` (icon `barbell`, `t('plans')`), `history` (icon `clock`, `t('history')`), `settings` (icon `settings`, `t('settings')`).
- **Style:** floating, `bg-forge-tabBg` (`rgba(20,20,22,0.85)` dark / `rgba(255,255,255,0.85)` light) + blur, top `border-forge-border`, `paddingTop 10 / paddingBottom 28`. Active item = `text-forge-accent` + icon `strokeWidth 2` + label weight 600; inactive = `text-forge-text/38` + `strokeWidth 1.6` + weight 500. Label 10.5px.
- **Scope note:** Re-skin the shell's appearance only. Wires to existing expo-router tabs without changing routes/behavior.

### ProgressRing (DSGN-05 — STATIC this phase)
- **Props:** `size` (default 80–104), `stroke` (default 8–11), `value: 0..1`, `color`, `trackColor`, `gradient?: [from, to]`, children (center content).
- **Impl:** `@shopify/react-native-skia@2.2.12` (installed) — two concentric circles, `strokeLinecap: round`, rotated -90deg start; gradient via Skia `SweepGradient`/`LinearGradient`. Track default `rgba(255,255,255,0.08)` dark / `rgba(0,0,0,0.06)` light.
- **STATIC:** Renders at target `value` with no mount animation. Animated fill is Phase 12 / MOTN-02 — do NOT add `useSharedValue`/animation here.

### Sparkline (DSGN-05 — STATIC this phase)
- **Props:** `data: number[]`, `width` (default 200–340), `height` (default 48–56), `color`, `fill?` (gradient area, default true), `showDot?` (last-point dot, default true), `strokeWidth?` (default 2–2.5).
- **Impl:** Skia path — normalize min/max with `strokeWidth+2` padding; gradient fill `color@0.35 → transparent`; last-point dot + soft halo.
- **STATIC:** No draw-on-mount animation (that is Phase 12 / MOTN-03). The `FullChart` axis-chart variant is NOT built in Phase 8 (Phase 12 dashboard/chart scope).

### Logo (DSGN-06 — component only, no asset swap per D-03)
- **Props:** `size` (default 64), `variant: 'gradient' | 'white'`, `from?`/`to?` (gradient stops, default `#FF7A2E`→`#FF2D55`).
- **Impl:** Ascend mark — two rising rounded bars + peak dot, `strokeWidth 7`. `gradient` = orange→pink stroke (standalone); `white` = white stroke (sits inside gradient tile/AppIcon).

### AppIcon (DSGN-06 — component only, no `app.json` swap per D-03)
- **Props:** `size` (default 56), `radius?` (default `size*0.28` squircle), `from?`/`to?`.
- **Impl:** Gradient squircle (`linear-gradient(135deg, from, to)`) containing white `Logo` at `size*0.62`, with soft brand-colored drop shadow.

### Icon (shared)
- **Props:** `name` (enum from `lib.jsx`: barbell, ascend, flame, clock, chart, settings, plus, check, checkCircle, chevronRight/Left/Down, ellipsis, close, grip, play, pause, trash, pencil, spark, trophy, user, bell, globe, scale, arrowUp, arrowRight, wifi, wifiOff, eye, lock, mail, list), `size` (default 20), `color` (default currentColor → token), `strokeWidth` (default 1.8), `fill?`.

## Internationalization (I18N-01, I18N-04)

- **Scaffold (D-09/D-10):** `react-i18next` + `expo-localization`, single default namespace, **flat keys mirroring `I18N` 1:1** (`signIn`, `myPlans`, `lastTrained`, …). Module-scope `app/lib/i18n.ts`; `LocaleBootstrap` reads `fm:language` and calls `i18n.changeLanguage()` before the splash gate clears (`localeReady` gate alongside `fontsReady`).
- **Locale files:** Transcribe the full `I18N.sv` / `I18N.en` objects into `app/locales/sv.json` + `app/locales/en.json`. Function-valued strings become interpolations:
  - `setsSavedBody` → `"{{n}} set sparade. Avsluta passet?"` / `"{{n}} sets saved. Finish workout?"`
  - `pbSub` → `"{{kg}} kg × {{reps}} reps"` (both locales)
  - `noSetsBody`, all others → direct string transcription.
- **Number/date formatting (I18N-04):** `Intl.NumberFormat` keyed off active locale (Swedish: space thousands separator, comma decimal — preserve `fmtNum` behavior `1 234,5`). Dates via `date-fns/locale` (`sv` / `enUS`) passed to `format()`. Stat numerals always tabular-nums regardless of locale.
- **Gallery proof (D-06):** sv↔en toggle flips at least one sample string live to satisfy ROADMAP success criterion 4.

## Copywriting Contract

This phase introduces no NEW user-facing screen copy — all strings are transcribed verbatim from the `I18N` map (D-09; do NOT author new copy). The gallery's own scaffolding labels (swatch names, section titles) are dev-only and exempt. Reference copy this foundation must support without truncation/overflow in both languages:

| Element | Copy (sv / en) | Source key |
|---------|----------------|-----------|
| Primary CTA examples | `Logga in` / `Sign in`; `Starta pass` / `Start workout`; `Skapa plan` / `Create plan`; `Klart` / `Done` | `signIn`, `startSession`, `createPlan`, `done` |
| Empty state heading | `Inga planer än` / `No plans yet`; `Inga pass än` / `No workouts yet` | `noPlans`, `noHistory` |
| Empty state body | `Skapa din första plan för att komma igång.` / `Create your first plan to get started.` | `noPlansSub` |
| Empty state body (history) | `Starta ditt första pass från en plan.` / `Start your first workout from a plan.` | `noHistorySub` |
| Error / offline state | `Du är offline — ändringar synkar när nätet är tillbaka.` / `You're offline — changes will sync when you're back online.` | `offline` |
| Destructive confirmation | `Avsluta passet?` / `Finish workout?` (+ `{{n}} set sparade…` body) ; `Avsluta utan att spara` / `Finish without saving` | `finishWorkoutQ`, `setsSavedBody`, `noSetsBody`, `finishWithoutSaving` |
| Destructive labels | `Logga ut` / `Sign out`; `Ta bort` / `Delete`; `Arkivera plan` / `Archive plan` | `signOut`, `deleteSet`, `archivePlan` |

**Destructive actions in this phase:** None executed — the gallery only *renders* destructive-variant buttons (ForgeButton `destructive`, SettingsRow sign-out). Real confirmations land in Phases 9/11. Destructive variant must visibly read as danger (`text-forge-danger`, bordered/ghost, never a solid-accent fill).
