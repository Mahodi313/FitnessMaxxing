# Phase 12 — UI Design Contract

> Visual and interaction contract for the read-side re-skin (History list, Session detail, Exercise chart) + the Home activity-ring dashboard hero. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Stack note:** This is an Expo / React Native + NativeWind 4 app, NOT a web/shadcn project. There is no `components.json` and no shadcn registry — the shadcn initialization gate and the registry-safety gate are **not applicable**. The design system is the in-repo **Forge** system landed in Phase 8 (`THEMES.forge` → `app/tailwind.config.js`, components in `app/components/ui/*`). This phase consumes those tokens; it declares no new tokens.
>
> **Re-skin scope (SKIN-06 + DASH-01..05 + MOTN-02/03):** Presentational re-skin of three existing read-side screens + a new Home hero, backed by **new read-only RLS-scoped RPCs** (D-23, `security invoker` + `stable`). The offline-first **write path / F13 hot path is untouched** (D-24) — `npm run test:f13-brutal` must stay green. New RPCs are read-only; no mutation defaults, query keys, or persister scope-bindings change.
>
> **PR markup OMITTED this phase (D-13, parallel to Phase 11 D-06):** No PR trophies, no e1RM hero, no celebration banner anywhere — every History row, session-detail exercise, and the chart renders plain. No inert/scaffolded PR slots. The mocks show these (FHistory row trophy 627-635, FSessionDetail PB trophy 739-746, FChart "Estimerat 1RM" hero 793-816) — Phase 12 strips them. **Phase 13 (PR-04/PR-05)** introduces the markup. The chart hero instead shows **real current-best + range delta** (D-12).

Keep `style()` only for shadow / opacity / Reanimated animated values. Applies to every session row, range/metric segmented control, stat card, and the ellipsis/back circular buttons in this phase.
