## Spacing Scale

Forge is a 4-point system. Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label inline gaps, tabular-nums kerning insets |
| sm | 8px | Compact gaps (banner control internal padding) |
| md | 16px | Default screen gutter; banner horizontal inset from screen edge; Settings row padding |
| lg | 20px | Banner internal padding (matches PR-banner inset) |
| xl | 28px | Major section breaks |
| 2xl | 48px | — |
| 3xl | 64px | — |

**Corner radii (Forge `borderRadius` tokens — do not re-derive):** `forge-sm` 10px, `forge-md` 14px, `forge-lg` 20px, `forge-xl` 28px. The countdown banner uses **`forge-lg` (20px)** to match the PR-banner overlay frame.

Exceptions:
- **44px minimum hit target** on both banner controls (`[Hoppa över]`, `[+30s]`) and the Settings chevron row — iOS touch-target floor + FLAG-1 a11y precedent (Phase 12). Visual height may be smaller; extend the tappable area via hit-slop to 44px.

## Color

Forge `THEMES.forge` palette (LOCKED, light + dark). Accent is the single 10% brand color; the timer is **not** a destructive feature, so it never reads red.

| Role | Token (dark / light) | Usage |
|------|----------------------|-------|
| Dominant (60%) | `forge-bg` `#000000` / `#FAFAF7` | Screen background (inherited; banner floats over it) |
| Secondary (30%) | `forge-surface` `#0E0E10` / `#FFFFFF`, `forge-surface2` `#18181B` / `#F2F1EC` | Banner base fill (opaque Forge surface — Phase 13 D-04 fix: the banner MUST sit on an OPAQUE surface base so the card title behind it never bleeds through); control chip backgrounds |
| Accent (10%) | `forge-accent` `#FF5A1F` / `#E14E10` | See reserved-for list below |
| Accent soft | `forge-accentSoft` `rgba(255,90,31,0.14)` / `rgba(225,78,16,0.10)` | `[+30s]` control background tint; optional banner accent wash (clipped to the 20px radius, Phase 13 D-04) |
| Success | `forge-success` `#30D158` / `#1E9E45` | NOT used by the timer (reserved for PR delta) |
| Destructive | `forge-danger` `#FF453A` / `#D70015` | NOT used by the timer — the rest timer has no destructive action (`[Hoppa över]` is neutral, not danger) |
| Border | `forge-border` / `forge-borderStrong` | Banner hairline frame; Settings row dividers |
| Text | `forge-text`, `forge-text2`, `forge-text3` | Numeral = `forge-text`; control labels = `forge-text`; secondary line = `forge-text2` |

**Accent reserved for (explicit — never "all interactive elements"):**
1. The `[+30s]` extend control (accent or accent-soft fill — the affirmative "give me more time" action).
2. An optional thin accent progress indicator on the banner (e.g. a depleting accent underline/ring) showing rest-elapsed — accent-only, never red.
3. NOT the `[Hoppa över]` control — that is a neutral/ghost treatment (`forge-text2` on `forge-surface2`), because skipping is a calm, non-celebratory exit.

**Permission-denied state color:** use `forge-text2` (muted), NOT `forge-danger`. A denied OS permission is informational ("background ping off; in-app countdown still runs" — D-12), not an error.

## Motion (Forge §07 Motion table — LOCKED)

Default curve: **spring `damping 18 / stiffness 220`** (matches Phase 12 D-18 / Phase 13 D-19). All motion reduce-motion-aware (snap to final under `useReducedMotion()`).

| Surface | Animation | Duration | Source |
|---------|-----------|----------|--------|
| Countdown banner enter | Backdrop-less; card `translateY 24→0` + scale `0.96→1` via spring (sheet/overlay row of §07) | 240ms · spring | §07 "Sheet / overlay" |
| Countdown banner exit (skip / rest-end / next-set) | Fade + `translateY 0→-12` out | ~200ms | §07 toast/overlay precedent |
| Per-second tick | Numeral text swap only — **no per-second animation** (tabular-nums keeps width fixed; animating each tick would feel busy and waste battery) | — | restraint per §07 intro |
| PR-then-timer handoff (D-04) | PR banner plays its ~600ms celebration FIRST; the timer banner enters AFTER the PR banner's exit. Timer logical start is at log-time (timestamp), only the visual banner defers. | — | D-04 |
| Optional rest-progress indicator | Accent underline/ring depletes over the rest duration; reduce-motion → static | linear over rest | discretion |

**Reduce-motion:** under `useReducedMotion()` the banner appears with no translate/scale (opacity snap), the progress indicator is static, and the numeral still updates each second.

## Copywriting Contract

All strings flat-keyed (Phase 8 D-10), sv + en at parity (D-15/D-21). Existing keys: `restTimer` = "Vilotimer"/"Rest timer", `notifications` = "Notiser"/"Notifications", `haptics` = "Haptik"/"Haptics".

| Element | sv | en | Key (proposed — planner finalizes) |
|---------|----|----|------------------------------------|
| Primary CTA (banner — extend) | `+30 s` | `+30 s` | `restAdd30` |
| Banner control (skip / early-cancel, TIMER-05) | `Hoppa över` | `Skip` | `restSkip` |
| Banner eyebrow/heading (optional) | `Vila` | `Rest` | `restLabel` |
| Live countdown format | `M:SS` (e.g. `1:30`) | `M:SS` | rendered, not a key |
| Settings row value (on) | `På · {dur}` (e.g. `På · 2 min`) | `On · {dur}` | reuse `on`/`off` + duration formatter |
| Settings row value (off) | `Av` | `Off` | `off` |
| Duration picker title | `Vilotid` | `Rest duration` | `restDuration` |
| Duration custom entry | `Anpassad` | `Custom` | `restCustom` |
| Empty / disabled state (banner) | *(no banner renders when the timer is OFF — there is no empty state; the surface simply does not appear)* | — | n/a |
| Permission-denied helper (D-12) | `Notiser av — vilan räknas ändå ner i appen.` | `Notifications off — rest still counts down in the app.` | `restNoPermission` |
| OS notification title (D-15) | `Vilan är slut` | `Rest is over` | `restDoneTitle` |
| OS notification body (D-15) | `Dags för nästa set.` | `Time for your next set.` | `restDoneBody` |
| Error state | *(no network/data error surface — the timer is purely local; the only failure mode is "permission denied", handled above as an informational state, not an error)* | — | n/a |

**Destructive actions:** NONE. The rest timer has no destructive action.
- `[Hoppa över]` cancels the *scheduled notification*, not user data — neutral treatment, **no confirmation dialog** (one tap, instantly reversible by logging the next set). This matches D-02/TIMER-05: skip is a calm, friction-free exit.
- Finishing/abandoning the session while a rest runs silently cancels the pending rest + notification (CONTEXT discretion default) — no prompt, since the session-finish flow owns its own confirmation already.

## Interaction Contract (behavioral, for the executor)

| Trigger | Behavior | Geometry rule |
|---------|----------|---------------|
| Working-set "Klart" with timer ON (D-05/D-06) | Fire-and-forget AFTER `addSet.mutate` (Phase 13 D-17). Set timestamp at log-time; schedule OS notification; mount banner. | Banner floats; set list / input row / Klart **never shift** (D-01, same as PR banner D-09). |
| Warmup/dropset/failure set | Logs with NO rest auto-start (D-06). | — |
| Next working set while rest runs (D-03/D-07) | Cancel current rest + its notification; start a fresh full-duration rest; reschedule notification. | Banner re-renders in place. |
| `[+30s]` (D-02) | Extend end timestamp +30s; reschedule notification to new end. | Banner stays; numeral jumps up. |
| `[Hoppa över]` (D-02/TIMER-05) | End rest immediately; cancel scheduled notification; banner exits. | — |
| App backgrounded then foregrounded (TIMER-02) | Re-derive remaining time from the STORED end timestamp (never trust the JS interval). JS interval is display-only. **RESEARCH-FLAGGED** — mechanism owned by research. | Banner reflects reconciled time on return. |
| Rest reaches 0 (foreground) | Banner exits; if foregrounded, the in-app moment is enough (the OS notification covers backgrounded). | — |
| Settings: enable timer (D-13) | Trigger OS notification-permission prompt in-context. Reflect grant/deny into the row. | — |
| PR + rest on same set (D-04) | PR banner plays first (~600ms), then timer banner takes the top slot. Timer counts accurately from log-time regardless. | Single banner occupies the top slot at a time. |

**Gating (D-14):** OS notification fires only if `rest-timer ON` AND `fm:notifications` ON AND OS permission granted. The **in-app countdown is never gated** by `fm:notifications` — only the OS notification is. Vibration on the notification respects `fm:haptics` (D-15/D-18).
