08Android adaptation

What ports · what changes

90% of Forge ports cleanly because the design language is geometric and token-driven, not iOS-platform-specific. The deltas below are the only places to fork behaviour.

Ports as-is

  • All color tokens (NativeWind is cross-platform)
  • All typography scale + Inter Display via expo-font
  • All radii / spacing
  • Card layouts, list rows, input fields
  • PR celebration, activity rings, charts (Skia)
  • Reanimated animations (worklets work on both)
  • Offline-first TanStack Query persister

Needs an Android variant

  • Status bar (no Dynamic Island — use system bar)
  • Tab bar (Material 3 navigation, edge-to-edge)
  • Glass blur (Material elevation, not backdrop-filter)
  • Haptics (HapticFeedback API maps differently)
  • Back navigation (system gesture handling)
  • Date picker / segmented control (Material primitives)
Pattern iOS (current) Android delta
Tab bar Translucent w/ backdrop-filter: blur(20px), glass tint, 28pt home-indicator pad Solid Material 3 NavigationBar, no blur, edge-to-edge bottom, 24dp pad, ripple states on items
Header bar Large-title pattern; nav buttons in glass pills Standard 56dp app bar; nav as flat icon buttons; back arrow uses Material chevron
Status bar Auto via expo-status-bar; Dynamic Island honoured Translucent + edgeToEdge; light content on dark, dark on light
Haptics Set logged → impactMedium · PR → notificationSuccess Map to Haptics.impactAsync(Light/Heavy); Android lacks success/warning subtypes
Press state active:opacity-80 (NativeWind) Add android_ripple on Pressable: { color: rgba(255,90,31,0.12) }
Segmented control Custom SegmentedControl matches iOS visual Same component renders well on Android; swap to Material chips if Android Material 3 feel is preferred
Bottom sheet / overlay Inline-overlay pattern (PATTERNS.md landmine-safe) Same pattern. Optional: use @gorhom/bottom-sheet on Android for native sheet snap-points
Date format date-fns with sv locale Already locale-aware. Add en-US for V2 English ports
Font loading expo-font with Inter Display + Inter + JetBrains Mono Same. Confirm Inter Display ships at all 5 weights or fall back to Inter Tight
Drag handle react-native-draggable-flatlist + ScaleDecorator Works cross-platform. Long-press timer can feel slow on Android — tune to 280ms
Recommended approach

Ship iOS V2 launch without an Android branch in the codebase. When you greenlight Android, introduce Platform.select() at exactly the boundaries listed above — header, tab bar, status bar, haptics — and leave the rest token-driven. That keeps your existing PATTERNS.md conventions intact and avoids a parallel design system.

How to wire this into your repo

Token-first. Edit tailwind.config.js once, every screen inherits. Then upgrade components from the inside out.

1. Tokens tailwind.config.js Extend theme.colors with the swatch names above. Replace stock blue-600 usage with accent.
